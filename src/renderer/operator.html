🖥️ Mode Operasi Aplikasi

Server Mode

Tentukan peran komputer ini dalam sistem antrian. Simpan untuk menerapkan perubahan.

Nama ini akan disiarkan ke jaringan lokal dan dikenali oleh PC Client sebelah.
💡
Info Koneksi Manual: Berikan alamat IP di atas (127.0.0.1:8080) ke PC Client jika menghubungkan secara manual.
💻 Komputer ini diatur sebagai Client Mode

Komputer ini tidak menyimpan database, melainkan terhubung ke PC Server utama. Pilih server tujuan di kartu "Pilih Server Antrian" di samping.

Komputer ini bertindak sebagai Tuan Rumah (Server). Komputer client di jaringan lokal dapat menemukan server ini secara otomatis melalui UDP Discovery.

💡 Tips jika server di PC sebelah belum muncul otomatis:
  1. Pastikan kedua PC terhubung ke Wi-Fi / kabel LAN yang sama.
  2. Di PC Server, lihat IP Lokal di tab Pengaturan (misal: 192.168.0.175:8080).
  3. Ketik IP tersebut di kolom Hubungkan Manual lalu klik Hubungkan.
  4. Pastikan Windows Firewall di PC Server mengizinkan aplikasi SimpleAntrian (Private Network).

🖼️ Tampilan Layar Display

Format didukung: PNG, JPG, GIF, WebP. Maksimal 2MB.
Pilihan untuk menukar card video/foto menjadi besar utama di sebelah kiri dan nomor antrian berada di samping kanan secara proporsional.
Pilih monitor fisik yang ditargetkan untuk menampilkan Customer Display secara presisi.
Saat aktif, jendela Customer Display dikunci fullscreen dan Always-on-Top (level screen-saver). Display akan tetap tampil tanpa gangguan dan tidak bisa tertutup walaupun Anda membuka aplikasi lain di PC operator.
⭐ Survei Kepuasan Pelanggan (Layar Display)
Jika link ini dikosongkan (default), bagian tulisan "Puas dengan layanan kami?" dan QR code akan otomatis tersembunyi dari layar display pelanggan.
Pilih apakah layar display akan menampilkan kode QR untuk discan, tautan website teks saja, atau keduanya secara berdampingan.

🖥️ Teks Berjalan (Running Text) — Layar Display

Teks berikut akan ditampilkan bergantian (cycling) di bagian bawah layar display pelanggan. Tambahkan sebanyak yang diinginkan. Setiap teks akan terdeteksi bahasanya secara otomatis.

💡 Tips: Tambahkan teks dalam berbagai bahasa. Sistem akan mendeteksi dan menampilkan label bahasa secara otomatis.

🎬 Playlist Media (Video & Foto) Layar Display

🔊 Suara Panggilan (Text-to-Speech)

Pilih bahasa untuk memanggil nomor antrian dan loket. Mesin suara otomatis menggunakan rekaman jernih dan bebas dari bahasa Mandarin/China.
Panggilan suara dibacakan sesuai bahasa yang dipilih di atas (Bahasa Indonesia atau Bahasa Inggris). Jika opsi nama aktif, sistem akan menyebutkan nomor tiket beserta nama orang yang mengantri. Jika opsi panggil otomatis dicentang, menekan tombol Selesai akan menyelesaikan antrian aktif dan langsung memanggil antrian berikutnya secara otomatis.
