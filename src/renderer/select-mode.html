SimpleAntrian

Pilih mode operasional untuk memulai aplikasi antrian

🖥️
Server Mode
Komputer ini bertindak sebagai **pusat data**. Menyimpan database lokal (SQLite), menjalankan WebSocket server, memproses nomor antrian, dan menghubungkan integrasi WhatsApp. Layar display pelanggan lain akan terhubung ke komputer ini.
💻
Client Mode
Komputer ini bertindak sebagai **operator pembantu atau display saja**. Komputer ini tidak menyimpan database melainkan terhubung secara nirkabel ke komputer Server di jaringan lokal yang sama untuk sinkronisasi antrian.
